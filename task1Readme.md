#  Weather Data Visualization Project

##  Overview
This project demonstrates API integration and data visualization using Python.

It fetches real-time weather data from the OpenWeatherMap API and visualizes it using Matplotlib and Seaborn. It also includes an interactive dashboard built with Streamlit.

---

##  Features
- Fetch live weather data from API
- Extract key parameters:
  - Temperature
  - Humidity
  - Pressure
- Data visualization using:
  - Matplotlib
  - Seaborn
- Interactive dashboard using Streamlit

---

##  Technologies Used
- Python
- Requests (API handling)
- Matplotlib & Seaborn (Visualization)
- Streamlit (Dashboard)
